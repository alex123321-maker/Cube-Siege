## 4. Динамические выводы по результатам профилирования
- **O(1) Flowfield Queries**: время запроса p95 направления движения из кэшированного поля составляет от 47.0 µs до 77.0 µs на моба, оставаясь константным при любом масштабе толпы.
- **Spatial Hash Bucket Avoidance**: локальная выборка соседей в корзинах 2.5м занимает в среднем от 1.3 µs до 30.2 µs на моба, предотвращая квадратичный рост O(N^2).
- **Obstacle Rebuild Latency**: максимальная задержка пересчета поля при размещении/снятии препятствия составила 100.173 ms (нормативный лимит < 5.0 ms).
- **Алгоритмические бюджеты локомоции**:
  - **14 мобов**: 5.060 ms (норматив < 0.35 ms) — превышает лимит.
  - **20 мобов**: 6.791 ms (норматив < 0.50 ms) — превышает лимит.
  - **100 мобов**: 18.526 ms (норматив < 2.00 ms) — превышает лимит.
  - **500 мобов**: 135.695 ms (норматив < 8.00 ms) — превышает лимит.
- **Расход памяти**: размер кэша flowfield радиусом 36 клеток составляет ~499.6 KB на цель, полностью покрывая кольцо спавна 20–28 м.
