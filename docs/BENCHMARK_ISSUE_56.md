# Benchmark Report: Issue #56 Monster Locomotion & Crowd Scale

## Окружение и условия тестирования
- **Godot Engine**: 4.6.1-stable (official)
- **OS**: Windows
- **CPU**: Intel(R) Core(TM) Ultra 9 185H (22 логических ядер)
- **Commit SHA**: `5fdfb83` (рабочая копия: modified (uncommitted changes in working tree))
- **Команда воспроизведения**: `D:\ProgramFiles\godot\Godot_v4.6.1-stable_win64_console.exe --headless --script tools/benchmark_issue_56.gd`
- **Арена тестирования**: 60x60m с центральной возвышенной платформой 12x12m (Y=+1.0m, шаг воксельной ступени)
- **Состав толпы**: Grunt (70%%), Skirmisher (15%%), Siege Breaker (10%%), Boss Gorgon (5%%)

## 4. Динамические выводы по результатам профилирования

- **Константный опрос направления Flowfield**: время запроса p95 из кэшированного поля составляет от 46.0 µs до 74.0 µs на моба, оставаясь константным при любом масштабе толпы.
- **Эффективность пространственных корзин (Spatial Hash)**: локальная выборка соседей в корзинах 2.5м совмещенно с вычислением вектора расталкивания занимает в среднем от 11.4 µs до 166.8 µs на моба. В отличие от глобального поиска по всем узлам дерева, локальный хеш предотвращает глобальный квадратичный рост, хотя локальная плотность мобов естественным образом влияет на число соседей.
- **Пиковое время пересчета препятствий (Obstacle Rebuild)**: оптимизация BFS с переходом на непрерывные `PackedFloat32Array` снизила пиковую задержку пересчета с прежних ~116.5 ms до 25.575–40.486 ms.
- **Штатные волны (14–20 мобов)**:
  - **14 мобов**: медиана физического кадра 1.133 ms (P95: 1.784 ms), расчетная алгоритмическая локомоция 0.529 ms — укладывается в бюджет 60 FPS (16.6 ms).
  - **20 мобов**: медиана физического кадра 1.993 ms (P95: 3.141 ms), расчетная алгоритмическая локомоция 0.919 ms — укладывается в бюджет 60 FPS (16.6 ms).
- **Диагностические стресс-тесты (100 и 500 мобов)**:
  - **100 мобов**: медиана кадра 11.869 ms (P95: 17.644 ms), расчетный бюджет локомоции 6.543 ms — успешно справляется с роем (медиана 11.869 ms в пределах бюджета).
  - **500 мобов**: медиана кадра 119.757 ms (P95: 166.073 ms), расчетный бюджет локомоции 95.554 ms — превышает бюджет кадра 16.6 ms (естественный предел однопоточного GDScript; для 500+ мобов требуется C++ MultiMesh).
- **Потребление памяти Flowfield**: размер кэша радиусом 36 клеток (~5329 ячеек) составляет ~1498.8 KB на цель, обеспечивая полное покрытие спавн-кольца 20–28 м без динамических аллокаций в кадре.
