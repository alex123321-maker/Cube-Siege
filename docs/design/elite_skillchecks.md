# Канонические способности элиты

Девять способностей перенесены со страниц каталога «Скилчек абилки». Каждую
исполняет `EliteSkillController` на настоящем зомби, стрелке или таранщике;
модели и обычное поведение этих архетипов сохраняются. В обычных волнах элита
появляется после пятой волны. Песочница использует тот же типизированный каталог
`EliteSkillCatalog.Entry` и `EliteSkillController.attach`, включая обычные
таймеры, физику, урон и отмену способностей.

| Способность и источник | Поведение |
| --- | --- |
| [Тройной бросок](https://chatgpt.com/space/page_c14fe5d9b1a08191a5968b81ced0b9a5) | Три последовательных броска в текущие позиции героя; каждая метка фиксируется при своём броске. Снаряд проходит дугу, удар происходит при приземлении. Ловушки после удара нет. |
| [Удар с обратным взмахом](https://chatgpt.com/space/page_95353da2b24c8191b3649aa6c0c34e62) | Оба передних сектора видны сразу. Первый — 100°, второй — 70° и 75% дальности. Между двумя отдельными ударами есть пауза; второе движение анимации проигрывается обратно. Такой порядок и расположение секторов подтверждены HTML визуализации. |
| [Подземный шип](https://chatgpt.com/space/page_e4fdddd56b18819183f15900be113f28) | Точка фиксируется при предупреждении. Урон наносится один раз при появлении. Затем остаётся физический шип, учтённый навигацией, без повторного урона. |
| [Возвращающийся клинок](https://chatgpt.com/space/page_076791485d348191819e52d0ab06d326) | Реальный снаряд проходит линию туда, останавливается на 0,25 с и возвращается по той же линии. Отдельный контакт возможен на каждом проходе; сама линия безопасна. |
| [Прыжок с ударом](https://chatgpt.com/space/page_6d69c835c8588191a7014f560e7cc316) | Круг приземления фиксируется сразу. Сам монстр движется по дуге через CharacterBody3D.move_and_collide и остаётся в новой позиции. Удар связан с фактическим завершением движения; столкновение по пути отменяет удалённое попадание в прежней метке. |
| [Короткий огненный выдох](https://chatgpt.com/space/page_de0c96cedcd881918c5ea95cb92489e8) | Направление конуса фиксируется с начала подготовки. После неё действует настоящий урон в секунду внутри конуса; выход сбоку или за спину прекращает урон. |
| [Плевок с лужей](https://chatgpt.com/space/page_173c42cbdf048191ac8692c15d465d4c) | Снаряд идёт по прямой, не доворачивает и проверяет контакт по пройденному отрезку. В точке контакта с героем, препятствием или конечной точке остаётся лужа с ограниченным временем жизни и уроном при нахождении в ней. |
| [Мина под ногами](https://chatgpt.com/space/page_d96b8e0da0308191b51fc243dee0aab7) | Малая метка фиксируется, затем вооружается. Вооружение само по себе не наносит урон. Мина ждёт контакта, срабатывает один раз либо исчезает по времени. |
| [Короткий выпад](https://chatgpt.com/space/page_5cc04eec6084819189df66965ec34fb7) | Фиксированная полоса показывает путь. Монстр реально движется по ней через обычную MonsterLocomotion; урон следует контакту с телом, включая пересечение между кадрами. После выпада монстр останавливается на окно ответного удара. |

Числа первой версии — параметры [EliteSkillSpec](../../scripts/elites/elite_skill_spec.gd).
Секунды следуют исходным визуализациям; размеры перенесены с масштабом
20 единиц визуализации на 1 метр мира.
Урон, дальность активации и шестисекундная перезарядка — настройка первой версии
в рамках делегированного автором баланса, а не новые утверждённые значения из Page.
Обычная атака архетипа возможна между особыми атаками; подготовка, исполнение
и восстановление подавляют обычный AI, поэтому старые мгновенные удары не
срабатывают одновременно с особой атакой.

Урон огненного выдоха и лужи считается по реальному времени контакта. Первая
доза относится к фактической экспозиции; последующие выдаются с шагом 0,1 с,
остаток при выходе из области или завершении учитывается отдельно. Поэтому
частота контратак не зависит от количества physics-кадров. Смерть или отмена
канала отбрасывает недовыданный остаток, не создавая поздних попаданий.

По [правилам оглушения](https://chatgpt.com/space/page_45d20c1035a881919bc5b6625ba3c58e)
элита получает половину длительности и прерывает незавершённую атаку. Боссы
невосприимчивы к оглушению и продолжают подготовку. Смерть, удаление владельца,
сброс арены отменяют связанные эффекты без глобальных async-таймеров. Оглушение
останавливает подготовку, канал и будущие броски, но уже выпущенные снаряды,
вооружённые мины и появившиеся шипы продолжают действовать по своему времени.
Исчезновение шипа освобождает только принадлежащие ему блокировки: стена,
ресурс или другой шип в той же клетке продолжают блокировать навигацию.

Поведенческие регрессии находятся в
[test_elite_skillchecks.gd](../../tests/unit/test_elite_skillchecks.gd).
Инженерный PASS этих тестов не подтверждает читаемость из игровой камеры:
песочница и новые способности требуют отдельной актуальной записи движка.

Конечный захват использует общую обзорную арену, настоящие сцены архетипов,
`EliteSkillController` и движковую физику:

```powershell
python tools/capture_bosses.py --script tools/capture_elites.gd --marker ELITE_CAPTURE --stem elites --output screenshots_debug/elites/capture
```

Команда пишет PNG предупреждения, действия и завершения для всех девяти
способностей, дополнительные кадры выхода из огня/лужи, MP4, runtime report и
manifest с SHA коммита и исходников. Python helper ограничен общим deadline
305 с: рендер до 240 с, кодирование до 45 с, метаданные до 20 с. Запись Movie
Writer с fixed 30 FPS не измеряет производительность и не подтверждает баланс
или читаемость на процедурном рельефе. Свежие кадры требуют отдельного просмотра
и публикации для текущего SHA по [PR_VISUAL_MEDIA.md](../PR_VISUAL_MEDIA.md).
