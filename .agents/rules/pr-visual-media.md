# Медиа в комментарии PR

- Если задача меняет видимый результат или поведение игры (UI, модели, сцены, атаки, попадания, парирование, рывок, анимации, VFX), до создания PR прочитай [docs/PR_VISUAL_MEDIA.md](../../docs/PR_VISUAL_MEDIA.md) и подготовь реальные скриншоты/запись. Правки только в скриптах тоже могут требовать медиа.
- После создания PR и после push исправлений обязательно загрузи актуальные медиа **отдельным комментарием** через `gh pr comment --attach`. Это разрешённое исключение из запрета собственных reviews/статусных комментариев; отдельное согласование загрузки в рамках задачи не требуется.
- Укажи полный опубликованный head SHA, подписи и ограничения; закончи тело маркером `<!-- agent:review-loop -->`. Проверь URL вложений и их открытие/воспроизведение.
- До проверки опубликованных вложений и получения URL комментария не объявляй PR/review fixes готовыми. Тесты, файлы в Git, ссылки в описании PR и локальные картинки не заменяют загрузку.
- Если запись или загрузка недоступна, укажи точную причину и невыполненный шаг. Не пропускай медиа молча и не заявляй успешную передачу. Для изменений только документации или иной задачи без видимого результата медиа не требуются.
