# Workflow: /create-asset

Процесс создания и валидации 3D-ассетов для Cube Siege.

## Пошаговый сценарий

### Шаг 1: Правила стиля и референсы
1. Ознакомиться с правилами стиля в `blockbench-asset`.
2. Изучить существующие модели в `assets/models/characters/` для сохранения масштаба, сетки и палитры.

### Шаг 2: Создание/Редактирование в Blockbench
1. Сохранять исходный файл `.bbmodel` как канонический источник.
2. Проверить стабильность точки опоры (Pivot у ног $Y=0$), направления ($+Z$) и названий костей/анимаций.

### Шаг 3: Многоракурсный визуальный контроль
1. Сделать скриншоты модели минимум с 3 ракурсов (изометрия, фронт, профиль).
2. Проверить отсутствие артефактов геометрии и текстурных искажений.

### Шаг 4: Экспорт и импорт в Godot
1. Экспортировать игровую модель в `assets/models/` (или использовать конвертер `scripts/export_bbmodel_to_godot.py`).
2. Выполнить повторный импорт ассетов в Godot:
   ```bash
   godot --headless --editor --quit
   ```

### Шаг 5: Проверка в сцене игры
1. Разместить модель в тестовой сцене Godot.
2. Проверить работу материалов, освещения и воспроизведение анимаций.
